# Лабораторная работа №2  
# Восстановление работоспособности системы

## Цель работы 
Целью работы является базовое ознакомление с взаимодействием с системой контроля версий (на примере GitHub).

## Содержание работы
1) Клонировать/скачать проект из вашей 1-й лабораторной работы
2) Загрузить его в новый репозиторий для 2-й лабораторной работы
3) Удалить модуль/дополнительный функционал (в целом - добавить ошибку в программу)
4) Загрузить обновленную программу в репозиторий
5) загрузить из репозитория и проверить работоспособность
6) Выполнить откат к последней рабочей версии
7) проверить работоспособность программы
8) загрузить работоспособную программу в репозиторий

## Уточнения по выполнению работы
### Удалить модуль/дополнительный функционал (в целом - добавить ошибку в программу)
Здесь вы можете либо просто удалить модуль из вашего репозитория, тогда программа будет ссылаться на файл, которого не существует, 

либо удалить какую-нибудь функцию/добавить синтаксическую ошибку

### Проверка работоспособности вашего решения
Не более, чем демонстрация того, что ваша программа работает, добавьте скриншот и покажите, что программа работает.

### Выполнить откат к последней рабочей версии
Здесь вы можете пойти двумя путями:
1) либо производить манипуляции в браузере, тогда вам нужно будет нажать на надпись "commits" под зелёной кнопкой "code" и выбрать подходящий для вас вариант.

2) Вести взаимодействие с репозиторием через консоль (например, git revert HEAD~1).

Если выберите этот путь - я буду счастлив, но путь не самый простой, тут вам может помочь официальная документация Git:https://git-scm.com/docs/git-revert
